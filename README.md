# SinCombo

Приложение для строки меню macOS: Wi-Fi, Bluetooth, звук, календарь, VPN, аккумулятор и подписки на нейросети в одной панели. Состав и порядок блоков настраиваются.

ТЗ: https://claude.ai/artifact/NXm1VTgZQY1WkDVj5vpmPg · прототип: https://claude.ai/artifact/D7xgRm5Pjp8XcPP92Vu7gU

## Модули

| Модуль | Что делает | Реализация |
| --- | --- | --- |
| Календарь | Сетка месяца, события из системной базы календарей, создание событий | EventKit |
| Звук | Громкость, выключение звука, устройства вывода и ввода | CoreAudio |
| Wi-Fi | Питание, текущая сеть, подключение к сети | CoreWLAN, CoreLocation |
| Bluetooth | Питание, сопряжённые устройства, заряд | IOBluetooth, `system_profiler` |
| VPN | Переключатели системных VPN, время и трафик | `scutil --nc`, код из SinVpn |
| Аккумулятор | Заряд, источник питания, время, состояние | IOKit |
| Подписки | Лимиты и расход по подпискам на нейросети, даты продления | запросы к сервисам, связка ключей |

## Требования

- Mac на Apple Silicon, macOS 14 или новее.

## Установка

1. Скачайте `SinCombo.zip` со страницы [релизов](https://github.com/claudesiniakov/sincombo/releases) и распакуйте.
2. Перенесите `SinCombo.app` в «Программы».
3. Сборка подписана ad-hoc (без Developer ID): при первом запуске откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть».

Приложение запрашивает доступ к календарям, геолокации (без неё macOS не отдаёт имена сетей Wi-Fi) и Bluetooth — каждый только при первом обращении к своему модулю. После обновления macOS может спросить их заново: без Developer ID разрешения привязаны к конкретной сборке.

## Сборка

На сервере разработки Swift нет: сборка и тесты идут в GitHub Actions (`.github/workflows/ci.yml`). Тег `vX.Y.Z` публикует релиз.

- `Sources/SinComboCore` — логика без интерфейса, покрыта тестами.
- `Sources/SinCombo` — приложение.
- `scripts/build-app.sh` — собирает `SinCombo.app` и архив.
